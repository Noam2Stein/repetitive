# Arrays

An array is a collection where all elements have the same type. Arrays can be
created using standard Rust array literals.

Like in standard Rust, arrays can be either sized or unsized. Sized arrays
support more operations than unsized ones.

## Supported Operations

- Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Use as iterator
- Indexing (by integers and ranges)

## Pasting

Arrays currently cannot be pasted.

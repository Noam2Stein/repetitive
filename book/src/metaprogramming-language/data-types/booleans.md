# Booleans

Booleans can be created via the `true` and `false` keywords, or as the result of
operations.

## Supported Operations

- Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Unary operators: `!`
- Binary operators: `&&`, `||`, `&`, `|`, `^`

## Pasting

Booleans are pasted as either `true` or `false`.

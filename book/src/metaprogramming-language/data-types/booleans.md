# Booleans

Booleans can be created via the `true` and `false` keywords.

## Supported Operations

- Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Unary operators: `!`
- Binary operators: `&&`, `||`, `&`, `|`, `^`
- Use in the [`format!`] macro

## Pasting

Booleans are pasted as either the `true` or `false` keywords.
